# PlaitsVA - NTS-1

Oscillateur virtual analog inspire de Plaits (Mutable Instruments, MIT, E. Gillet).

- Shape : forme d'onde osc 1 (pulse -> pulse etroit -> saw)
- Alt (Shift Shape) : forme d'onde osc 2
- Detune : ecart osc 2 (0 a 12 demi-tons)
- Mix : niveau osc 2
- Sub : sous-octave

Compilation : onglet Actions > dernier run > Artifacts.
